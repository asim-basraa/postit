## How the ids are made

- A component's id is `DS.` and its name in camelCase: Text field is `DS.textField`.
- A variant's id puts the variant first: the Primary Button is `DS.primaryButton`, the Arrow right Icon is `DS.arrowRightIcon`.
- A component with one variant has only its component id.
- Figma has no ids of its own for these components, so these were set here; if Figma gains them (in a component's description or documentation link), they take over.

## Notes

- Checkbox and Radio, Hover: in Figma the stroke's stored colour is black while its variable `color/control/indicator-hover` is #8a8b8f, and Figma draws the stale black. The pages follow the variable. Re-applying the variable in Figma fixes the render.
- Segment item has no description in Figma; the one here was written for it.
- Fonts: Geist and Geist Mono (variable, OFL) are served from the project's asset store.
